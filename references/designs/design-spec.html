01Design tokens · v2 (R-T0)

Contract: every color token is an RGB triple (channels only, no rgb() wrapper, no commas). Consumption: color: rgb(var(--text)) or with alpha rgb(var(--text-2) / 0.62). This is required for Tailwind v4's <alpha-value> expansion (bg-up/40) and matches shadcn/ui's color contract.

Tailwind v4 hookup (engineering wires; designer just guarantees the triples):

@theme inline {
  --color-bg:         rgb(var(--bg));
  --color-surface-1:  rgb(var(--surface-1));
  --color-text:       rgb(var(--text));
  --color-text-2:     rgb(var(--text-2));   /* alpha applied at site */
  --color-up:         rgb(var(--up));
  --color-down:       rgb(var(--down));
  --color-mint:       rgb(var(--mint));
}

Generates utilities bg-bg, bg-surface-1, text-text, text-text-2/[0.62], bg-up/40, etc.

Inter Variable web font (R-T0.e)

Self-hosted variable font for non-Apple platforms. Apple users land on SF Pro via the system stack. Engineering deliverable: ship /public/fonts/InterVariable.woff2 (latin subset). At display sizes, Inter's optical body is heavier than SF Pro 800 — we ramp 800 → 750 on non-Apple to compensate:

@supports not (font: -apple-system-body) {
  .t-display, .t-display-2, .t-display-3, .t-display-4, .t-display-5 {
    font-weight: 750;
  }
}

Tabular numbers — opt in

SF Pro and Inter both default to proportional figures. Numbers must opt in with the .tnum / .tabular class (defined in styles.css):

.tnum, .tabular {
  font-variant-numeric: tabular-nums;
  font-feature-settings: "tnum" 1, "cv11" 1;   /* cv11 = single-story 4 */
}

SSR-safe SVG IDs (R-T0.f)

Sparkline + PriceChart use React.useId() for gradient IDs. Never Math.random() — under Next.js App Router, server and client produce different IDs → hydration mismatch + missing gradients.

function Sparkline({ data, up, … }) {
  const reactId = React.useId();
  const gradId = `spk-${reactId.replace(/:/g, '')}-${up ? 'u' : 'd'}`;
  …
}

Known incompatible (R-T0.h) — design accepts these limitations

iOS continuous corner (squircle)CSS border-radius is quarter-circle. Web has no native superellipse. Negligible ≤16px, visible at 22+px. Acceptable drift documented here.
Dynamic system colors (Apple accent that follows OS setting)Static tokens only on web. System-blue rendered as our --mint brand accent regardless of user OS setting.
iOS haptics (navigator.vibrate)Silently no-op on iOS Safari; works on Android Chrome. Haptic spec is aspirational; iOS PWA gets no haptic feedback today.

09Data shapes

TypeScript interfaces matching what every screen consumes. Implement in db/schema.ts (Drizzle) per the v1 implementation plan; types should be inferred from Drizzle $inferSelect.

// One quoted security
interface Symbol {
  symbol:     string;            // PK · uppercase ticker
  name:       string;
  exch:       string;            // "NASDAQ" | "NYSE" | …
  sector:     string;            // "Tech" | "Semis" | "ETF" | …
  currency:   string;            // "USD" only in v1
  type:       "EQUITY" | "ETF";
}

// Live quote (from quote_cache, 30s TTL)
interface Quote {
  symbol:        string;
  price:         number;
  prevClose:     number;
  change:        number;         // price - prevClose
  pct:           number;         // (change/prevClose)*100
  dayHigh:       number;
  dayLow:        number;
  volume:        number;
  overnightPct?: number;        // pre/post-mkt session, when available
  updatedAt:     Date;
  intraday:      number[];       // 48 points, 30-min bars, for sparkline
}

// User's brokerage account
interface Account {
  id:        string;
  broker:    string;             // "Fidelity" | "Schwab" | …
  name:      string;             // "Individual" | "Roth IRA"
  last4:     string;             // "2645"
  currency:  string;
  createdAt: Date;
}

// A single recorded transaction
interface Transaction {
  id:         string;
  accountId:  string;
  symbol:     string;
  kind:       "BUY" | "SELL" | "DIV" | "SPLIT" | "FEE" | "CASH";
  quantity:   number;            // shares (or ratio numerator for SPLIT)
  price:      number;            // per-share, or per-share div, or ratio denom
  fees:       number;
  executedAt: Date;
  note?:      string;
}

// Derived position (NOT persisted — computed via lib/portfolio.ts)
interface Position {
  symbol:        string;
  account:       Account;
  qty:           number;
  avgCost:       number;         // weighted average
  marketValue:   number;         // qty * quote.price
  cost:          number;         // qty * avgCost
  unrealized:    number;         // marketValue - cost
  unrealizedPct: number;
  todayPL:       number;         // qty * quote.change
  pctOfPortfolio:number;
}

// Historical OHLC point
interface HistoryPoint {
  date:     Date;
  open:     number;
  high:     number;
  low:      number;
  close:    number;
  adjClose: number;
  volume:   number;
}

// Dividend record (for the bar chart on Symbol Detail)
interface Dividend {
  symbol: string;
  exDate: Date;
  amount: number;             // per-share
}

11Accessibility

  • Contrast — all text passes AA at 4.5:1. The two semantic colors on dark have been chosen for ≥4.5: --up (#34D399 on #0A0A0C → 11.3:1), --down (#FB7185 on #0A0A0C → 6.4:1).
  • Color is never the only signal — every +/− value carries an explicit sign (▲▼ or +/−) in addition to color. Required for color-blind users.
  • Hit targets ≥ 44 × 44 px. The 32-px .iconbtn uses a 44-px tap area via padding-trick on the parent.
  • Tabular nums on every price/quantity so screen-readers and side-by-side comparisons line up.
  • Reduced motion — replace all transitions > 100ms with instant; never animate route transitions.
  • VoiceOver labels — every pill / sparkline / chart needs aria-label like "MSFT, $421.92, up 3.05% today, intraday chart".
